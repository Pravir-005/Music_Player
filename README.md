# Python Music Player
A simple and beginner-friendly **Music-Player Application built using Python**, with audio playback handled by **Pygame**.
This Project Allows users to load and play Downloaded Songs dierctly from their system with basic controls.

## Features:
- Play Local '.mp3' and '.wav' files
- Pause/Resume playback
- Stop Music
- Volume Control
- Load Songs using File Explorer
- Simple and Clean Tkinter GUI

## Technologies Used:
- **Python 3**
- **Tkinter** (GUI)
- **pygame.mixer** (Audio Playback)

## Installation:
1) Clone the Repository: (git clone https://github.com/Pravir-005/Music_Player.git)
2) Navigate to the Project Folder: (cd Basic Music Player/)
3) Install Dependencies: (pip install pygame)

## How it Run:
python main.py
